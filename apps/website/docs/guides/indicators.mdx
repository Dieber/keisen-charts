## Custom indicators

`registerIndicator` returns a mountable Chart component. Provide `calc` and `figures` (line / bar styles) in the descriptor.

For dynamic main overlays and sub panes (visibility / params), see `useKlineIndicator` in [Main / sub panes](./panes.mdx).
