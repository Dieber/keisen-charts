K 线 `t` 始终是绝对时间。`timezone` 只影响轴标签、面板等如何格式化显示。

- prop：`timezone`（`"UTC" | "local" | IANA`）
- 受控回调：`onTimezoneChange` / Vue `timezone-change`
- 图内：`useKlineTimezone`

与 `locale` 正交：locale 管「中/英」等文案，timezone 管「按哪个时区读钟」。
