## 自定义指标

`registerIndicator` 返回可挂载的 Chart 组件。描述里提供 `calc` 与 `figures`（线 / 柱样式）。

若要按设置动态组装主图叠加与副图（显隐 / 改参），见 [主图 / 副图](./panes.mdx) 中的 `useKlineIndicator`。
