- `resolution`：默认 `"1"`；支持 `"1" | "5" | … | "1D" | "1W" | "1M"`
- `symbol`：透传给 getData / subscribe 的标的 id

:::tip
用静态 `data` 时，切换 symbol / resolution 建议加 `key` 强制换图，或自己换数组。`getData` 路径由 DataController 按依赖刷新。
:::
