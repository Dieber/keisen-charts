## 安装


<Tabs groupId="package-manager">
  <TabItem value="npm" label="npm" default>

```bash
npm install @keisen-charts/react
# 或
npm install @keisen-charts/vue
```

  </TabItem>
  <TabItem value="pnpm" label="pnpm">

```bash
pnpm add @keisen-charts/react
# 或
pnpm add @keisen-charts/vue
```

  </TabItem>
  <TabItem value="yarn" label="yarn">

```bash
yarn add @keisen-charts/react
# 或
yarn add @keisen-charts/vue
```

  </TabItem>
  <TabItem value="bun" label="bun">

```bash
bun add @keisen-charts/react
# 或
bun add @keisen-charts/vue
```

  </TabItem>
</Tabs>

peer：`react@^18 || ^19` 或 `vue@^3.5`（随你选的包）。
